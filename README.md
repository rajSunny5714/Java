## 📂 Repository Structure

| 📁 Folder | 📖 Description |
|-----------|----------------|
| `basics` | Java fundamentals, variables, loops, conditions, input/output. |
| `operators` | Arithmetic, logical, relational, bitwise and assignment operators. |
| `arrays` | 1D & 2D arrays with practice problems. |
| `strings` | String methods, StringBuilder, StringBuffer and manipulation programs. |
| `methods` | User-defined methods, recursion and parameter passing. |
| `constructors` | Default, parameterized and constructor overloading examples. |
| `keywords` | Java keywords like `this`, `super`, `static`, `final` etc. |
| `oopsconcepts` | Encapsulation, Inheritance, Polymorphism and Abstraction. |
| `inheritance` | Single, Multilevel, Hierarchical inheritance programs. |
| `interfaces` | Interfaces, multiple inheritance and default methods. |
| `collections` | List, Set, Map, Queue, Stack and Collection Framework. |
| `wrapperclasses` | Boxing, unboxing and wrapper class methods. |
| `exceptionhandling` | Try-catch, throws, throw, finally and custom exceptions. |
| `multithreading` | Threads, Runnable, synchronization and thread lifecycle. |
| `concurrent` | Java Concurrent package and multithreading utilities. |
| `filehandling` | Reading, writing and managing files using Java IO. |
| `input/output` | Streams, BufferedReader, BufferedWriter and IO operations. |

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/rajSunny5714/Java.git
```

2. Open the project in **IntelliJ IDEA** (or any Java IDE).

3. Navigate to any topic folder.

4. Compile and run the Java file.

```bash
javac FileName.java
java FileName
```
